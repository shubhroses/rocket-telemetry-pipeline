# telemetry_analytics

The dbt project of the rocket engine telemetry pipeline. The [repository README](../../README.md) describes each model, the Redshift objects the project expects and how to run it.

| Path | Contents |
|---|---|
| `models/staging/` | `sources.yml`, which declares the table Airbyte loads, and the view `stg_telemetry_readings` |
| `models/core/` | `fact_telemetry_readings` |
| `models/marts/` | `engine_performance_summary` and `daily_anomaly_trends` |
| `models/schema.yml` | Column descriptions and 39 of the 44 generic tests; the other 5 are in `models/staging/sources.yml` |
| `packages.yml`, `package-lock.yml` | `dbt_utils` 1.3.0, installed by `dbt deps` |

`analyses/`, `macros/`, `seeds/`, `snapshots/` and `tests/` hold only a `.gitkeep` file.

The skeleton of this folder (the layout and comments of `dbt_project.yml`, `.gitignore` and the empty folders) was generated by `dbt init`, which copies the starter project that ships with dbt-core (dbt Labs, Apache-2.0).
